VALORANT × Discord

뽕짝이

Discord에서 VALORANT 플레이어의 계정 정보와 최근 경기 통계를 편리하게 확인할 수 있도록 제작된 Discord 봇입니다.

기능 살펴보기 서비스 흐름

주요 기능

뽕짝이가 제공할 VALORANT 통계 기능입니다.

👤

Riot 계정 연결

사용자가 Riot 계정을 인증하고 자신의 VALORANT 데이터를 조회할 수 있도록 OAuth 기반 계정 연결을 제공합니다.

🏆

티어 조회

인증한 사용자의 VALORANT 경쟁전 티어와 관련된 정보를 Discord에서 확인할 수 있도록 제공합니다.

📊

최근 전적

사용자가 자신의 최근 경기 결과와 경기 통계를 Discord 명령어를 통해 확인할 수 있도록 제공합니다.

서비스 원칙

뽕짝이는 Riot Games API 정책을 준수하는 것을 목표로 합니다.

🔐 사용자 인증

사용자 데이터를 조회하기 전에 Riot 계정 인증 및 필요한 동의 절차를 거치는 것을 목표로 합니다.

📋 API 정책 준수

Riot Games API의 사용 정책과 서비스 요구사항을 준수하여 서비스를 개발합니다.

🚫 아이템 상점 기능 제외

VALORANT 아이템 상점 조회 기능은 제공하지 않습니다.

본 프로젝트는 Riot Games의 정책을 준수하며, 전적 및 계정 관련 정보 조회 기능을 중심으로 개발할 예정입니다. 향후 기능을 추가할 경우에도 Riot Games의 API 정책 및 이용 약관을 준수하는 범위에서만 추가할 예정입니다.
